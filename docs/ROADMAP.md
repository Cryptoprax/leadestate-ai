# Vayon OS Roadmap

This roadmap describes strategic sequencing, not committed delivery dates.
Priorities will be validated against security, customer value, and platform
readiness before implementation.

## Phase 1: Platform foundation

- Establish module boundaries, shared contracts, configuration conventions, and
  provider composition.
- Define tenant context, audit event standards, monitoring expectations, and
  feature-flag governance.
- Build a reusable design system and navigation model.

## Phase 2: Authentication and organizations

- Introduce secure authentication and session lifecycle management.
- Support organization creation, membership, invitations, and lifecycle states.
- Establish role-based access control and tenant-aware administrative workflows.

## Phase 3: CRM and properties

- Deliver modular lead, contact, pipeline, activity, and assignment capabilities.
- Add property inventory, availability, media, matching attributes, and listing
  workflows.
- Create stable integration boundaries between CRM and property modules.

## Phase 4: AI and messaging

- Add governed AI assistants with evaluation, monitoring, and human escalation.
- Support channel-independent messaging, conversation history, templates, and
  delivery status.
- Preserve consent, auditability, and tenant-level configuration throughout.

## Phase 5: Automation

- Introduce event-driven workflows, triggers, conditions, actions, schedules,
  approvals, and failure handling.
- Provide operational visibility into workflow execution and recovery.
- Enable controlled no-code composition through the Workflow Builder.

## Phase 6: Marketplace

- Define versioned extension contracts and an application/module registry.
- Support reviewed first-party and partner modules.
- Add installation governance, compatibility checks, permissions, metering, and
  tenant-level enablement.

## Continuous workstreams

Security, accessibility, performance, auditing, data governance, documentation,
developer experience, analytics, and reliability evolve across every phase.
