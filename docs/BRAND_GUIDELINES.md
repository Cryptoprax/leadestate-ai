# VAYON Brand Guidelines

## Source of truth

`public/assets/brand/logo-master.png` is the only authoritative VAYON artwork. It must not be redrawn, traced, stretched, rotated, or geometrically altered. All shipped raster variants are reproducible derivatives generated by `scripts/generate-brand-assets.mjs` using deterministic crop, color, compositing, and resize operations.

## Shared components

- `BrandLogo` renders the complete symbol and VAYON wordmark. Its default `auto` variant follows the active VDS light or dark theme.
- `BrandIcon` renders the symbol for collapsed navigation and compact contexts.
- `BrandWordmark` renders the wordmark when the symbol is already present in the surrounding composition.

Application UI must import these components from `@/components/brand`. Do not recreate the mark with text, CSS, Lucide icons, inline SVG, initials, or page-local image references.

## Usage

Keep the original aspect ratio and use `object-contain`. Use `BrandLogo` in expanded navigation, public headers and footers, authentication, onboarding, and branded entry points. Use `BrandIcon` only where the available width cannot safely accommodate the lockup, including the collapsed product sidebar and mobile compact controls.

The mark needs clear space around its rendered bounds and must never be clipped by `overflow`, flex shrinking, or fixed-width containers. Accessible links wrapping the mark must provide a destination label; standalone components already expose the VAYON name.

## Regeneration

Run `node scripts/generate-brand-assets.mjs` after the master file is deliberately replaced with an approved official revision. Never edit generated derivatives independently because those edits cannot be reproduced or audited.
