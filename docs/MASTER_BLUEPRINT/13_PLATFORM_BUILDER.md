# Platform Builder

## Purpose

AtlasOS Builder Studio enables authorized teams to configure products and
tenant experiences through validated metadata. Builders produce versioned
definitions, not unrestricted code. Every definition supports draft, preview,
validation, approval, publish, rollback, ownership, and audit history.

## Builder suite

### Navigation Builder

Defines menus, groups, labels, icons, destinations, ordering, product/module
requirements, permission visibility, hierarchy scope, localization, and
responsive behavior.

### Dashboard Builder

Composes layouts, widgets, filters, data sources, refresh behavior, empty states,
drill-down actions, and role-specific defaults.

### Page Builder

Builds governed content and application pages from approved sections,
components, bindings, actions, SEO metadata, breakpoints, and accessibility
constraints.

### Module Builder

Defines module manifests, entities, permissions, navigation, views, events,
configuration, dependencies, lifecycle, and packaging for reviewed modules.

### Workflow Builder

Creates triggers, conditions, actions, delays, approvals, branches, retries,
limits, error handling, and execution observability.

### Form Builder

Defines fields, layouts, validation, conditional visibility, defaults,
permissions, localization, submission actions, and accessibility metadata.

### Report Builder

Selects governed datasets, dimensions, measures, filters, grouping,
visualizations, schedules, exports, and access policy.

### Permission Builder

Composes roles and scoped grants from a reviewed permission catalog with
conflict detection and effective-access preview.

### Theme Builder

Configures approved design tokens, typography, logos, color modes, component
variants, and brand assets while preserving contrast and usability rules.

### Email Builder

Creates responsive, localized templates from approved blocks with variables,
preview data, consent classification, sender policy, and delivery testing.

### Notification Builder

Defines in-app, push, email, or messaging notifications with templates,
audience, priority, preference handling, throttling, and fallback.

## Governance

Schemas are versioned and migrations deterministic. Publication validates
permissions, references, accessibility, dependencies, performance budgets, and
environment policy. High-impact changes can require dual approval and staged
rollout. Builders must expose provenance and effective configuration.
