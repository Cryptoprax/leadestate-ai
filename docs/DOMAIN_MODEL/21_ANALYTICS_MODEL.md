# Analytics Model

MetricDefinition specifies semantic name, unit, aggregation, dimensions, owner, freshness, privacy class, and version. MetricObservation is immutable; snapshots and projections optimize consumption. DashboardWidget references a query definition rather than owning business data.

Funnels connect marketing → lead → qualification → viewing → offer → deal → commission. Every metric declares timezone, currency conversion policy, grain, numerator/denominator, late-event handling, and access scope. AI metrics distinguish recommendation from approved or executed outcomes.
