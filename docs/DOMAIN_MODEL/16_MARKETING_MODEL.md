# Marketing Model

Campaign coordinates audience, channel, content, properties, budget, schedule, attribution, and outcomes. Audience is a versioned segmentation definition; attribution connects touchpoints to contacts/leads.

Campaign lifecycle: Draft → Scheduled → Active → Paused → Completed/Cancelled. Events include CampaignCreated, CampaignScheduled, CampaignLaunched, CampaignPaused, CampaignCompleted, EngagementRecorded, and LeadAttributed. Consent and channel rules override campaign intent.
