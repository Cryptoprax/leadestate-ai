# Document Model

Document is governed content with type, classification, owner, related subjects, lifecycle, current immutable version, signatures, retention, and legal-hold metadata. DocumentVersion references a MediaAsset and checksum.

Lifecycle: Draft → InReview → Approved → Active → Superseded/Expired → Archived. Signature lifecycle is Requested → Viewed → Signed/Declined/Expired. Documents include mandates, contracts, disclosures, IDs, offers, leases, invoices, and reports. Storage location is opaque.
