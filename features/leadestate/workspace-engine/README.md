# Universal Workspace Engine

The engine renders reusable business-object command centers. AtlasOS Builder owns workspace definitions, tabs, actions, widgets, permissions, and relationships. LeadEstate modules supply domain data and module-specific widget content only. The engine has no persistence and does not own business rules.

Heavy tabs are configuration-marked for lazy resolution by route-level consumers. Accessibility uses landmarks, labels, keyboard-focusable links/actions, semantic status, and responsive overflow/collapsible patterns.
