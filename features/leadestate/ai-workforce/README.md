# AI Workforce Platform

Sprint 15 registers seven organization-scoped AI employee archetypes, capability contracts, trusted knowledge sources, recommendation/task records, and a human approval queue. All employees are provisioned as `inactive`; tools are empty; no provider, inference, prompt, autonomous execution, or CRM mutation exists.

Approval is a governance decision only. It updates the proposal/task status and writes shared activity evidence, but never dispatches work. Future runtimes must remain behind provider policy, budgets, telemetry, evaluation, safety, and explicit execution authorization.
